# 原曲改音色、改歌词：代码审查与改进优先级

本文基于当前工作树的代码审查和自动化测试，不是实际歌曲的听感评测。用户提供的 2.52 秒参考和 ASR 漏词案例可解释部分风险，但尚不能据此给模型、预处理各自分配影响百分比，也不能验证“第一梯队”的排名。

## 先按任务选择流程

| 任务 | 建议起点 | 主要检查项 |
| --- | --- | --- |
| 保留歌词和原唱表演，只换音色 | SVC + 原曲纯人声 + 目标歌手参考 | 分离残留、叠唱、F0、参考音域 |
| 保留曲调，替换歌词 | SVS + 校正后的 Score + 新词 | 音符、歌词起音、延音、休止和每字时长 |
| 保留歌词，用 SVS 重唱 | Melody / Score 小段比较 | 原始 F0 表情与重新演唱自然度的取舍 |
| 同时换词和换音色 | SVS Score + 新词对齐 + 目标歌手参考 | 先用同一参考确认对齐，再比较音色 |

SVC 的内容条件来自原唱音频的 Whisper 编码，因此并不承担换词任务。Score 能解除对原唱连续 F0 的依赖，但仍然依赖正确的音符和歌词时序；错误的乐谱不会因为选择 Score 而自动修好。参考留空时，工作台从原曲选择音色，不能据此获得另一个歌手的音色。

## 当前已落地的基础能力

- 长曲 SVS 的服务、CLI 和界面默认采用 Score，仍可选择 Melody。
- 自动参考优先选择 8–15 秒候选；不足 8 秒会提示。现在还会检查 RMS、峰值/削波、静音比例、有声比例和 F0 音域；异常参考会标记具体原因。ASR 回退选择其他参考后，质量提示按最终实际片段更新。短录音不会被自动“补长”。用户可填写参考起止秒数固定一段已知干净的人声。
- 目标与外部参考分别控制人声分离；纯人声可以跳过分离。长曲工作台另有独立的目标/参考去混响开关，默认关闭，避免过度处理损失气声和辅音；设置会保存到 manifest。
- ASR 空结果、占位音符和 F0 异常具有人工复核标记；恢复预处理时回填片段 F0 诊断。人工 metadata 不再清掉独立的 F0 风险。
- 新建项目可导入 MIDI 或 metadata，跳过目标片段 ASR/ROSVOT；仍需目标 F0 提取、分段以及 SVS 参考转录。
- MIDI 导入支持速度变化、主唱轨选择和短休止，拒绝静默裁剪复音。缺词须显式提供替换歌词，且保留人工复核提示。
- 长曲工作台可逐段编辑音节、音高、时长和 note_type，也可以导出 JSON/MIDI、导回同一片段，只使该段失效，并保存乐谱历史与版本校验。
- 新建项目的人工乐谱作为分段依据，保护连续长音并恢复 F0 漏检的演唱窗口；已有项目的局部编辑保持其他片段时间边界不变。
- A/B 独立保存 Melody / Score，可加原始歌词/对齐形成四组试听；历史版本不覆盖，界面提供并排播放器与明确的“采用此版本”。
- 渲染与人工验收分开：待对齐/F0 复核、待试听、已验收。验收绑定当前输入及音频，支持撤回、保留历史与仅导出已验收整曲。

F0 诊断目前是有声比例、相邻帧大幅跳变和孤立掉音位置的启发式检查，不是模型输出的置信度。界面可显示异常帧，F0 可导出为 50Hz JSON，修改后导回单段并重新生成；旧曲线和音频保留。长间奏会降低全曲有声比例，真实的大跳也可能触发提示，应结合片段原声检查，不能据此自动平滑整条曲线。

## 最值得继续投入的地方

### P0：可靠的乐谱导入与人工修正流程

本轮已修复 [MIDI 解析器](../preprocess/tools/midi_parser.py) 的全曲速度换算、合并多轨后裁剪重叠、吞并短休止和连续延音丢失歌词问题。现在逐段积分完整 tempo map，要求明确选择多轨 MIDI 的主唱轨，并拒绝复音冲突、缺少 note-off 和孤立延音。未提供替换歌词时，缺词会报错；显式提供替换歌词时，可以生成待复核的初始对齐。

导入已校验非负时间、音符总时长、数组数量、音高/休止语义和延音对应关系。仍应使用单声部主唱轨；复音伴奏需要单独处理。下一步可增加直观的冲突位置预览和乐谱修复建议，不把歧义自动“修好”。

新建人工乐谱项目已使用乐谱活动区间规划分段，因此 F0 漏检不再决定该演唱窗口是否存在，也不会在连续长音内部产生切点。短休止仍结合声学能量判断是否可切。已有项目导回单段乐谱不调整全曲边界；跨段移动音符和重新规划整曲仍需进一步支持。

“导出当前片段 → 编辑音高/时长/音节/note_type → 导回同一项目 → 只使受影响片段失效”已打通，界面也支持直接编辑表格。历史乐谱和旧音频保留；旧页面提交会进行版本校验。下一步可在表格上增加同步波形、钢琴卷帘和每字拥挤区间可视化。

### P0：区分生成成功和人工验收

[服务层](../longform/service.py) 已将渲染与人工验收分开，`completed` 仅表示音频生成成功。复核诊断后记录人工决定，再试听并验收当前音频。歌词、乐谱、参考/F0 内容、生成结果或选用版本变化后，旧验收不再有效；旧页面也不能误验收另一个版本。原始诊断和验收历史保留。

普通合并和自动生成后的合并仍可用于试听草稿；“导出已验收整曲”要求所有演唱片段的当前版本已验收。旧项目不会自动视为验收通过，缺少生成来源记录的旧 WAV 需重新生成或采用新比较版本后验收。这解决状态混淆，但不能代替人耳判断。

字数不同的新词目前依靠启发式映射，保留总时间轴不代表重音和韵母落点正确。应展示每字实际时长、拥挤区间和行与乐句的对应关系。只修复非法 `note_type=3` 能避免数据错误，不能替代人工判断一字多音。

### P1：SVC 的纯人声与参考质量

长曲界面现在提供目标和参考的独立去混响开关，并记录分离后的电平、削波、静音和人声/伴奏相关性指标；异常结果会提示人工复核。仍可增加独立主唱/和声处理、纯人声与外部伴奏成对导入，以及分离前后试听。去混响应逐例比较，过度处理也会损伤辅音和气声。

参考的 8–15 秒是工作建议，不是质量保证。当前已检查有效演唱秒数、削波、过低电平、静音比例和 F0 有声比例，并允许手动指定参考起止点；仍需增加残余伴奏/混响检测和更可靠的目标音域覆盖判断。整曲使用同一参考有助于一致性，但不能保证音色不漂移。

长曲 SVC 全量运行在未指定手动变调时，`auto_shift` 现在根据参考和全部有声目标 F0 计算一个统一半音值，并应用到每个片段；单段重试仍保持原生逐段计算。保留原曲调性时建议关闭自动移调、固定 `pitch_shift=0`；需要移调时应先确定全曲统一值，并同步处理伴奏。换音色无需默认匹配参考的绝对音高。

### P1：把 F0 诊断变成可修正的数据

增加与波形、MIDI 同步的 F0 曲线和异常时间点；在有声区域检查短暂掉音、孤立倍频/半频、超出参考音域。支持局部手动修正和原始曲线回退。只有拿到提取器的真实置信度或经标注数据校准后，才应显示“置信度”。

### P1：完善对比和客观验收

当前 A/B 已独立于正常生成：每次比较使用新的 ID 和目录，保留当前选用音频、验收与整曲混音；单个版本失败不把主片段标记失败。支持当前词 × Melody/Score，以及可选的原始词/对齐 × Melody/Score。界面可并排试听，并明确采用当前歌词的某个版本。输入已改变的旧版本不能被误用。

原词组使用原始乐谱，人工修改音符后两组可能同时存在对齐差异，不能把结果全归因于歌词。原词组目前用于诊断试听，不能直接覆盖当前歌词。尚需增加响度匹配、盲听记录和更清晰的逐字时序指标。

建议选取慢歌、快歌、密集伴奏、叠唱各若干个 15–25 秒片段；固定参考、种子和参数，按一次一个变量比较。换词关注人工漏字/错字、字头时间、节奏和音准；换音色关注相似度、原唱泄漏、表情与伪影。盲听前匹配响度，歌声 ASR 分数只作辅助。

### P2：混音与分段一致性

当前模型和整曲导出均为 24 kHz，原始高采样率伴奏混回时也会被降采样。可将人声生成采样率与最终导出采样率分开，提供 44.1/48 kHz 混音以保留伴奏高频；上采样本身不能恢复模型人声的高频细节。

[合并模块](../longform/core.py) 已有精确时间轴和短边缘淡化，仍可增加全曲响度控制、人声/伴奏增益、片段间音色与响度检查、可选统一混响。不要用逐片段峰值归一化掩盖原本的强弱变化。

## 当前验证范围

自动测试覆盖流程恢复、时间轴、真实 MIDI 文件转换、乐谱编辑往返、复核标记和 UI 事件；本地 HTTP 接口已验证保存音高、导出 JSON/MIDI、选轨导入和保留其他片段。模型边界使用替身，尚未完成真实歌曲听感验收；当前环境也没有可用的受控浏览器进行截图核对。下一轮验收应先选取同一首歌的困难片段，比较“自动对齐”和“人工校正 Score”，再比较参考与分离策略。参见[操作说明](longform.md)。

### 长参考音频的补充处理

如果参考人声连续超过 28 秒且没有明显停顿，系统会在连续有声区间内自动寻找 8–15 秒候选窗口，避免因没有静音切点而无法生成 prompt。手动填写参考起止时间时仍优先使用手动区间，并检查其中确实包含有声帧。
